# Context schema guidance

Use `PROJECT_CONTEXT.md` for the current truth, not a timeline. Use `DECISIONS.md` for rationale and reversals. Use `SOURCE_MAP.md` to avoid duplicating large source material. Use `OPEN_ITEMS.md` only for unresolved work. Rewrite `SESSION_HANDOFF.md` after substantive tasks.

Recommended context budget:

- PROJECT_CONTEXT.md: 1–3 pages
- SESSION_HANDOFF.md: under ~800 words
- OPEN_ITEMS.md: only active items
- DECISIONS.md: append material decisions, newest first
- SOURCE_MAP.md: concise pointers

If a repository already uses files such as `CONTEXT.md`, `MEMORY.md`, `PROJECT_STATE.md`, or a documented equivalent, adapt to that convention and do not create parallel sources of truth.
